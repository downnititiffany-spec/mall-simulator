# 阶段 4/5 RuntimeProfile 管理页面接线（2026-10-08）

## 实施

- 新增 `/runtime-profiles` 管理页，接入现有运行环境列表、详情、新建、编辑、连通测试、激活和停用 API；来源列表供配置绑定使用。
- 页面按服务端角色矩阵开放给 `admin` 与 `data_dev`；其它角色不能从路由进入或看到导航入口，后端 `runtime:manage` 仍是最终权限边界。
- 显示环境类型、来源、状态、版本、更新时间及逐项测试结果；激活要求本页最近一次测试全部通过，再二次确认，服务端激活仍会重新跑检查。ACTIVE 环境不允许从页面编辑；停用会说明没有 ACTIVE 环境的风险并确认。
- 只接受安全凭据引用，不提供明文密码/token 输入；连接参数仅显示于有 `runtime:manage` 权限的页面。
- 权限对账将 7 个 RuntimeProfile 路由接入前端；`GET /runtime-profiles/active` 不单独请求，因为列表已返回 ACTIVE 状态。其余未接线路由继续逐项登记。
