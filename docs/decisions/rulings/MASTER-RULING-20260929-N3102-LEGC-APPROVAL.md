## 被批准的契约要点

1. `byRegion` 首版实际按源字段 `city_level` 分组，页面名称明确为“城市等级销售分布”，不得描述为省/市行政区或地图能力。
2. 多日窗口不把每日 distinct 买家数或订单数相加后伪称窗口唯一人数/订单数；首版只提供可加总维度度量，金额占比按所选窗口聚合金额重算。
3. 分类仅以叶子分类作为展示/聚合粒度，保留 `category_id=-1` 或未匹配维表的唯一 unknown 类别；父类字段只作说明，不重复汇总。
4. 新增分类/城市等级 ADS 及 MySQL 服务表采用新的加性迁移，不修改历史 Flyway 迁移；实现由独立 oracle 和 ADS→服务库→API→页面证据验收。
