## 1. 状态与证据口径

### 1.1 任务状态（V2.1 §2.2，只允许以下取值）

`TODO / READY / IN_PROGRESS / BLOCKED / REVIEW / DONE_LIMITED / DONE / REGRESSED / DEFERRED / N/A`

- 代码、表、接口、页面**单独存在不算完成**。
- 代码写完只能进 `REVIEW`；**通过目标测试并附证据**才可标 `DONE`。
- 部分达成（例如算法类存在但未接入生产链）只能标 `DONE_LIMITED`，并在证据列写清缺哪一半。

### 1.2 证据分级（E1–E5）

| 级别 | 含义 | 最小可接受证据 |
|---|---|---|
| E1 | 编译/静态检查 | `mvn -o -DskipTests compile` 或 `package` 的 SUCCESS 输出 |
| E2 | 模块自动化测试 | 模块测试用例全绿 + 用例名（单测/集成测试，内存或 20–100 条数据） |
| E3 | **本地真实链** | 真实 MySQL/Spark/Hive 上的 55 条黄金链：runId、快照 ID、指标值、对账输出 |
| E4 | 集群链 | 固定 seed 1,000 条集群链 + 本地/集群同值比较 |
| E5 | 普通员工可用页面路径 | 页面路径 + DOM/接口证据（不经 `runtimeProfileId`、不暴露 Hive 表名） |

> E1 为本看板补充定义（V2.1 §2.2 只显式给出 E2–E5）。**未达 E3 的数据链一律不得写"链路完成"。**
