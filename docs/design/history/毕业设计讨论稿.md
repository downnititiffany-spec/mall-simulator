# 第四章 数据仓库设计

## 4.1 数仓整体设计

本系统针对电商平台产生的用户行为数据和交易数据，设计了一套基于 Hive 的离线数据仓库体系。

考虑到原始业务数据结构复杂、分析需求多样，系统采用经典的四层数据仓库架构：

```
                 业务数据源

                     |

                     ↓

              ODS 原始数据层

                     |

                     ↓

              DWD 明细数据层

                     |

                     ↓

              DWS 汇总数据层

                     |

                     ↓

              ADS 应用数据层

                     |

                     ↓

          数据分析 / AI智能分析
```

------

## 4.1.1 ODS层设计

### 设计目标

ODS（Operational Data Store）层主要用于保存业务系统产生的原始数据。

该层特点：

- 保留原始数据结构
- 不进行复杂业务加工
- 为后续数据处理提供数据来源

本系统ODS层主要包含：

- 用户信息数据
- 商品信息数据
- 用户行为日志数据
- 订单交易数据

# 6.1 模块设计背景

1. 了解数据库结构
2. 掌握 SQL 语法
3. 编写查询语句
4. 理解分析结果

例如用户想知道：

> 最近一个月销量最高的商品是什么？

传统方式：

```
SELECT
    product_name,
    SUM(amount)
FROM
    ads_product_sale
WHERE
    dt BETWEEN '20260901'
    AND '20260930'
GROUP BY
    product_name
ORDER BY
    SUM(amount) DESC
LIMIT 10;
```

这要求用户具备 SQL 能力。

因此，本系统引入大语言模型 API，实现：

```
自然语言问题

↓

↓

自动生成SQL

↓

查询数据仓库

↓

AI解释结果

↓

生成分析建议
```
