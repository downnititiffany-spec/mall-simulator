# Slice10: 权限登录（§2.1 角色 × §3.2 权限模块）— Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL per superpowers:subagent-driven-development or executing-plans.

**Goal:** 项目根需求闭环：五类角色中的可用子集（管理员 admin / 运营 operator / 数据分析 analyst，
其余角色延后）接入 Web 与 API；登录后按角色展示页面；无 token 一律 401 → 前端跳登录页。

**Architecture:** 轻量会话式认证（不引 Spring Security 全家桶，仅用 spring-security-crypto
的 BCrypt）：`sys_user(username, password_hash, real_name, role, status)` +
`user_session(token, user_id, expires_at)`（UUID token，24h 有效期，登出即删）。
`AuthInterceptor` 校验 `Authorization: Bearer <token>`，写入 ThreadLocal `CurrentUser`；
白名单仅 `/api/v1/auth/login` 与 `/api/v1/metrics/health`。角色规则：
ADMIN 可访问全部（含生成/采集/流水线/指标管理）；OPERATOR/ANALYST 仅分析/Dashboard/AI/决策。
前端：`Login.vue` + 路由守卫（requiresAuth → 无 token 跳 /login）+ 导航按角色过滤 + 登出。

**Tech Stack:** 既有栈 + `org.springframework.security:spring-security-crypto:6.2.x`（仅密码编码，
不引入任何 filter/自动配置——需注意导入包为 `org.springframework.security.crypto`）。

**外部约束:** ① 演示种子账号 admin/admin123、operator/operator123、analyst/analyst123，
密码仅存在于 BCrypt hash；② 冒烟脚本 `run-demo.ps1` 必须先登录拿 token 再调业务 API；
③ 现有 Service 层集成测试不走 HTTP 不受影响；新增 HTTP 级测试用
`@SpringBootTest(webEnvironment=RANDOM_PORT)` + TestRestTemplate。

### Task 2: 认证后端
- `auth/entity/SysUser`、`UserSession` + Mapper × 2；`AuthService`（login/logout/me/verifyToken）；
  `AuthController`（POST /api/v1/auth/login、POST /logout、GET /me）；
- `auth/AuthInterceptor`（HandlerInterceptor）+ `auth/CurrentUser`（ThreadLocal holder）；
- `WebConfig`：注册拦截器 + 白名单；配置类与 MapperScan 登记 `auth.mapper`。

### Task 3: 测试
- `AuthServiceTest`：正确密码→token 可解析；错误密码→异常；登出后 token 失效；
- `AuthHttpTest`（RANDOM_PORT + TestRestTemplate）：无 token→401；错误 token→401；
  admin 登录→访问 /api/v1/metrics/health 200、访问 /api/v1/generator/scenarios 200；
  operator 登录→访问 /api/v1/analysis/sales 200、访问 /api/v1/generator/scenarios 403。

### Task 4: 前端
- `api.js`：axios 拦截器注入 Authorization；401 → 清 token 跳 /login；
- `Login.vue`；`router.js` 全局前置守卫 + meta.requiresAuth；App.vue 顶栏用户/登出；
  侧边导航按 `user.role` 过滤（admin 才显示生成/采集/流水线入口）。
