1. 数字引用格式：`（见 experiments/xxx.json，YYYY-MM-DD 实测）`；正文数字以 2026-09-11
   复核的 run 22 证据包为准（当前唯一 ACTIVE 快照 `S20260901_22`）；
2. 未运行实验（集群分档、真实 LLM 消融、性能优化前基线、决策 EFFECTIVE 效果）只能写
   "待环境/待补测"，不得预写结论或用估算值填充；
3. 借鉴项目（text-to-sql-main 等）仅参考实现思路，引用时注明来源；
4. 每章按"问题→方法→实现→实验→分析"闭环组织（§15.2）。
