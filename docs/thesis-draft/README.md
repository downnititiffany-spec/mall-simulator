## 写作约定

1. 数字引用格式：`（见 experiments/xxx.json，2026-09-06 实测）`；
2. 未运行实验（集群分档、真实 LLM 消融）只能写"设计了对照实验，待环境执行"，不得预写结论；
3. 借鉴项目（text-to-sql-main 等）仅参考实现思路，引用时注明来源；
4. 每章按"问题→方法→实现→实验→分析"闭环组织（§15.2）。
