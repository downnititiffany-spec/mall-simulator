# 摘要（初稿）

随着电商平台用户行为数据的规模持续增长，传统关系型数据库在数据量到达百万级后难以满足
分析时效与口径统一的要求，而业务运营人员直接编写 Hive SQL 门槛较高，大模型生成 SQL 又存在
字段幻觉、口径错误与越权风险。针对上述问题，本文设计并实现了一套基于 Spark 大数据平台和
智能分析模型的电商用户行为分析系统。

系统以数据工程为可信基础：通过 Java 模拟商城与场景化数据生成器产出可复现的业务事件，
经事务 Outbox 与断点采集进入 ODS；在 Hive 四层数仓（ODS/DWD/DWS/ADS）之上，由
Scala 编写的 Spark SQL 作业完成清洗、去重、主题聚合与指标计算，经由质量规则（金额对账、
主键去重、空值率、枚举白名单）校验后，以"快照版本 + 唯一活跃指针"机制发布到 MySQL 指标服务库；
Vue 前端固定看板提供经营大盘、转化漏斗、商品热度等分析页面。

在智能分析方面，系统构建了面向数仓语义的业务语义层，实现"主题识别→Schema 裁剪→
大模型生成受约束 SQL→四层安全校验→至多一次自动修复→只读执行"的受控 Text-to-SQL 流程，
并将真实查询结果与执行证据（SQL、行数、耗时、口径、快照）绑定后生成结构化解释；
建议经人工审核进入决策任务，执行后按前后窗口对比评价效果，形成
"发现—解释—行动—复盘"的业务闭环。大模型服务不可用时，系统自动降级到规则模板，
不阻断固定看板与数据处理链路。

实验结果表明：黄金数据全链路 9 项核心指标与标准答案完全一致；100 条安全/越权测试题中，
正常查询全部可执行，越权请求全部被拦截（100%）；固定看板 API 在 30 并发下 P95 延迟
由 7.4 秒优化至 29 毫秒；基于 Spark 的四层作业链在真实 Spark 3.5.1 上完成
1.4 万至 13 万事件规模的全量处理验证。系统在本地、单节点与远程集群三类运行环境间
仅通过切换连接配置迁移，为大数据分析与可信智能分析的结合提供了可复现的实现参考。

**关键词**：Spark SQL；Hive 数仓；用户行为分析；Text-to-SQL；SQL 安全校验；证据链；
决策闭环
